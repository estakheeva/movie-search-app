# Movie Search

Приложение для поиска фильмов через API Кинопоиска.

## Демо
[https://meek-kheer-dbbff2.netlify.app/](https://meek-kheer-dbbff2.netlify.app/)

## Функциональность
- Поиск фильмов по названию через API Кинопоиска
- Добавление фильмов в избранное (localStorage)
- Создание и редактирование подборок фильмов
- Переключение тёмной/светлой темы
- Поддержка русского и английского языков
- Адаптивность для мобильных устройств

## Технологии
- Vue 3 (Composition API)
- Vue Router
- Bootstrap 5
- i18n

## Запуск локально

npm install
npm run serve

# Movie Search

Movie search application using Kinopoisk API.

## Demo
[https://meek-kheer-dbbff2.netlify.app/](https://meek-kheer-dbbff2.netlify.app/)

## Features
- Search movies by title via Kinopoisk API
- Add movies to favorites (localStorage)
- Create and edit movie collections
- Dark/light theme toggle
- Russian and English language support
- Responsive design for mobile devices

## Technologies
- Vue 3 (Composition API)
- Vue Router
- Bootstrap 5
- i18n

## Local Setup

npm install
npm run serve
